# SentinalX
SentinalX is a modular cybersecurity toolkit designed for security professional, students, and system administrators.
The project is built with a focus on clean architecture, extensibility, and practical security utilities.

## Community Edition

Features include:

- Port Scanner
- DNS Lookup
- WHOIS Lookup
- Password Strength Checker
- Hash Generator
- Ping Utility

## Vision

To build an extensible cybersecurity toolkit that demonstrates professional software engineering while providing practical security tools.
